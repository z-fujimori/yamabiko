# 🎤 Yamabiko（やまびこ）

**マイク入力をリアルタイムでスピーカーから出力するシンプルなアプリ**

Tauri + React + TypeScript で構築されたクロスプラットフォーム対応アプリケーション。

## 🎯 主な機能

- **マイク入力 → スピーカー出力**: Web Audio API を使用したリアルタイム音声処理
- **遅延調整（Delay）**: 出力にタイムラグを追加してハウリング軽減
- **音量制御**: スライダーで出力レベルを調整
- **キーボードショートカット**: Enter キーで ON/OFF 切替
- **ヘルプモーダル**: 使用方法を確認できる「?」ボタン
- **アプリ内更新**: 起動時に更新を確認。新しい版があると「Update」を表示し、クリックで更新・再起動（音声OFF時のみ）

## 自動更新のリリース設定

この機能を搭載する最初のバージョンは、Releasesから手動でインストールしてください。
以降は起動時の確認、または左上の「更新を確認」から更新できます。
通信エラー時は再試行でき、更新中は音声の開始を無効にします。

配布前に [Tauri updater用の署名鍵](https://v2.tauri.app/plugin/updater/) を一度だけ用意します。
Appleのコード署名証明書とは別です。

```sh
npm run tauri signer generate -- -w ~/.tauri/yamabiko-updater.key
```

GitHubの Settings → Secrets and variables → Actions に設定します。

| 種類 | 名前 | 値 |
| --- | --- | --- |
| Variable | `TAURI_UPDATER_PUBLIC_KEY` | 生成した `.key.pub` の内容 |
| Secret | `TAURI_SIGNING_PRIVATE_KEY` | 生成した `.key` の内容 |
| Secret | `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 鍵生成時のパスワード（設定した場合） |

秘密鍵はリポジトリに入れず、安全な場所にバックアップしてください。同じ鍵を将来の更新でも使います。
CIは公開鍵をアプリ設定に埋め込み、更新ファイルと署名、`latest.json` を生成します。
macOS・Windows両方のビルドが成功した後にドラフトを公開します。
新しい `vX.Y.Z` タグで配布してください。既に公開したタグの再利用は避けてください。

開発用設定の `pubkey` は空です。実際の更新テストには、上記公開鍵を設定した署名済みの旧版と、
同じ鍵で署名した新しいリリースが必要です。ブラウザプレビューでは更新ボタンを表示しません。

## ⚠️ 使用上の注意

**ハウリング防止のため、イヤホンの使用を強く推奨します。**

スピーカーとマイクが近い場合、音が増幅してハウリングが発生する可能性があります。

## 🛠️ 技術スタック

- **フロントエンド**: React 18 + TypeScript + Tailwind CSS
- **デスクトップフレームワーク**: Tauri
- **ビルドツール**: Vite
- **状態管理**: Zustand

## 🎮 操作方法

| 操作 | 機能 |
|------|------|
| ON/OFF ボタン | マイク通しを有効/無効 |
| Enter キー | ON/OFF 切替（ショートカット） |
| 音量スライダー | 出力音量を調整（OFF時も操作可。次にONにすると反映） |
| 遅延スライダー | 出力タイムラグを調整（OFF時も操作可。次にONにすると反映） |
| ? ボタン | ヘルプモーダルを表示 |
| Escape キー | モーダルを閉じる |

## 💡 トラブルシューティング

### マイク許可が出ない

- **本番環境**: HTTPS 必須。HTTP では動作しません
- **永続的な拒否**: ブラウザ設定からマイク許可を手動で変更してください
  - Chrome/Edge: 設定 → プライバシーとセキュリティ → サイト設定 → マイク
  - Firefox: アドレスバーの🔒 → サイト情報 → マイク
  - Safari: 設定 → Webサイト → マイク

### ハウリングが発生する

- イヤホンを使用してください
- 遅延（Delay）を大きめに設定してください
- 音量を下げてください

---

### Teams・ブラウザなどにマイク入力が届かない

Yamabiko は ON の間だけマイクを使います。会議アプリと併用するときは、まず
**内蔵マイク＋有線イヤホン**で確認してください。Yamabiko のマイク取得では
エコーキャンセルを無効にしています（[WebKit の他アプリ入力減衰の報告](https://bugs.webkit.org/show_bug.cgi?id=294623)への回避策）。
ハウリング防止のため、音量を下げてイヤホンで使用してください。

1. Yamabiko を OFF にして、会議アプリの入力メーターやテスト録音が正常か確認します。
2. macOS の「サウンド > 入力」と会議アプリで、意図したマイクを選択します。会議アプリのマイク権限とミュートも確認します。
3. Yamabiko を ON → OFF にして、会議アプリの入力音量が変化するか確認します。逆の起動順でも試します。
4. Bluetooth 使用時だけ発生する場合は、入力を内蔵マイクか USB マイクに切り替えて比較します。
   [Bluetooth マイク使用時には音声モードが切り替わります](https://support.apple.com/en-us/102217)。
5. 改善しない場合は会議中の Yamabiko を OFF にし、macOS を更新して再確認してください。

報告時には OS・Yamabiko・会議アプリ・ブラウザのバージョン、入出力デバイス、起動順、
起動のみ（OFF）でも発生するか、OFF で復旧するかを添えてください。
調査と実機検証の手順は [issue #29](https://github.com/z-fujimori/yamabiko/issues/29) を参照してください。

### 入力マイクを選ぶ

音声を OFF にして「入力マイク」から内蔵マイクや USB マイクなどを選び、ON にします。
ON 中は取得したマイクの名前を「使用中」に表示します。Teams 側の入力設定と照合してください。
「システム既定のマイク」は OS / WebView の既定選択を使います。Bluetooth マイクを避けたい場合は、
内蔵マイクなどを名前で明示的に選んでください。選択はこの画面を開いている間だけ保持します。

初回は権限の関係で名前や一覧が取得できないことがあります。一度 ON にしてマイク使用を許可し、
OFF に戻してから選択してください。一覧はマイクの接続変更・アプリへの復帰・「再読込」で更新します。
一覧の表示・再読込だけではマイクを取得しません。

明示的に選択したマイクが使えない場合、別のマイクでは開始しません。
使用中のマイクの切断・トラック終了を検知した場合は音声を停止し、再選択を案内します。
一覧取得エラーだけで切断とは判断しません。OS / WebView によって接続変更の通知が遅れる場合は
「再読込」を押してください。これは Yamabiko の入力設定で、Teams や OS の既定デバイスは変更しません。
